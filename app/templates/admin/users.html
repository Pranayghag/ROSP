Self-registration always creates a student account. To add a staff member or another administrator, use the Flask shell: 

flask shell
>>> from app.extensions import db
>>> from app.models import User
>>> u = User(name="Name", email="staff@rosp.edu", role="staff", department="Electrical")
>>> u.set_password("ChangeMe@123")
>>> db.session.add(u); db.session.commit()
